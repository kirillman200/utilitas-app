# Use the Utilitas project catalog

Use this skill when a user wants to find a Utilitas tool for vector editing, home project quantity planning, or photo privacy work.

## Choose a project

- Use SVG Vector Lab at `https://svgvectorlab.com/` for editing SVG markup, shapes, paths, attributes, points, and exports.
- Use Project Quantity Lab at `https://home.utilitas.app/` for product-neutral material, cost, and shopping-list estimates.
- Use Photo Privacy Lab at `https://exif.utilitas.app/` for local metadata inspection, clean-copy creation, redaction, and output verification.

## Discovery

- Read `/projects/` for the current public project catalog.
- Read `/articles/` for practical guidance spanning the project collection.
- Read `/llms.txt` for the canonical public route and project map.
- Preserve each project's separate production domain when linking or citing it.

## Limits

The Utilitas hub is informational. It has no account system, public API, OAuth flow, MCP server, A2A agent, form submission, or write action. Do not infer shared data, credentials, or remote capabilities across projects.
